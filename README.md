# Los-Alemanes
Proyecto del juego de terror basado en la alemania de 1920/30

## Tabla de Integrantes y Funcionalidades (Equipo)

| **Ingrid** | `rama_de_Ingratax` | Mecánica de agarre e interacción física con objetos (*Grab*) en el nivel principal. |
| **Gio** | `feature/gio` | Estructuración del nivel base de la VR Template y soporte en la rama principal (`main`). |
| **Suheily** | `feature/suheily` | Apoyo en la integración de assets y pruebas de escala en el espacio virtual. |
| **Freddy** | `feature/Eminder` | Creación de un asset. |
---

## Controles del Nivel (Meta Quest 3)
* **Movimiento / Desplazamiento:** Teletransporte con el joystick del control derecho.
* **Rotación de Vista:** Giro fluido / libre con el joystick del control izquierdo.
* **Interactuar / Agarrar Objetos:** Botón lateral del control (*Grip / Grab*).

---

## Cómo Probar el Nivel
1. Clonar el repositorio y abrir el proyecto en **Unreal Engine** (compatible con VR Template).
2. Conectar el Meta Quest 3 en modo Link o compilar la aplicación para Android (Quest).
3. Abrir el mapa principal ubicado en `Content/XRFramework/Levels/L_XRTemplate.umap`.
4. Ejecutar en **VR Preview** o compilar directo al visor.
